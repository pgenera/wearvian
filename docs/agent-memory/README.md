# agent-memory — archived Claude Code memory store

Verbatim snapshot of the per-project memory an AI assistant (Claude Code) accumulated while working
on wearvian, preserved here so the knowledge survives independently of `~/.claude/`. Each `*.md` is
one note (kebab-case slug + frontmatter `type`); `[[name]]` in a note body links to another note by
its slug. `MEMORY.md` is the index.

**These are point-in-time observations, not live state.** Some are dated/ephemeral (battery
baselines, queued task lists, "current" version numbers) and may be stale. Curated, current
operational guidance lives in the repo-root `AGENTS.md`; use this archive for extra detail and
history, and verify against current code before relying on any file:line citation.

Snapshot taken 2026-07-22.
